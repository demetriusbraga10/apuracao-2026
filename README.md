# Apuração do 2º turno 2026 · ao vivo

Página única que lê os resultados do TSE direto no navegador, a cada 5 segundos: Brasil, regiões, estados e exterior, com mapa e projeção para 100% das urnas.

- Fonte: arquivos públicos de resultados.tse.jus.br (eleição 6258, presidente).
- A projeção supõe que as urnas que faltam em cada estado votem como as já apuradas nele. É uma conta, não uma previsão.
- `historico.json` guarda os pontos coletados antes da publicação; a partir daí cada navegador acumula os seus.
